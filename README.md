# Fernhaven

Fernhaven is a calm, first-person woodland exploration game built with React, Vite, and Three.js. Wander through a living forest, look for wildlife, and click animals to discover a little about them. There is no score or timer, so you can explore at your own pace.

## Getting started

Install dependencies and start the local development server:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite in your browser.

To create and preview a production build:

```sh
npm run build
npm run preview
```

## How to explore

- Select **Wander in** to enter the forest.
- Use **W**, **A**, **S**, **D** or the arrow keys to move and turn. On touch screens, use the on-screen movement controls.
- Drag the scene to look around.
- Scroll, or use the zoom slider, to look closer or farther away.
- Click an animal to open its information card. Press **Escape** or close the card to return to exploring.
- Use the sound control to toggle the forest ambience.
