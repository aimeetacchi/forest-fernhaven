# Woodland animal models

The animated deer and fox models in this folder are by Quaternius, downloaded from Poly Pizza.

- Deer: https://poly.pizza/m/T6Cs7tmMHJ
- Fox: https://poly.pizza/m/Bc97C66HKi

Both model pages identify the assets as CC0 / Public Domain. The models may be reused without attribution; this note is kept as a courtesy record of their source.

- Hawk: https://poly.pizza/m/RkN6MEbP6g by Sherkiz. The Poly Pizza listing identifies this animated model as Creative Commons Attribution 3.0 (CC BY 3.0): https://creativecommons.org/licenses/by/3.0/. The model is used in the forest with its included Fly animation.
- Badger: https://poly.pizza/m/fXBbhQr-T80 by Poly by Google. Licensed Creative Commons Attribution 3.0 (CC BY 3.0): https://creativecommons.org/licenses/by/3.0/.
- Squirrel: https://poly.pizza/m/2WqY_AFEn-M by Poly by Google. Licensed Creative Commons Attribution 3.0 (CC BY 3.0): https://creativecommons.org/licenses/by/3.0/.
- Hedgehog: https://poly.pizza/m/Uu0PXwt2nU by Quaternius. Public Domain (CC0); the model includes an idle animation.
- Bunny: https://poly.pizza/m/irZjWFARyl by Quaternius. Public Domain (CC0); the model includes a walk animation.
- Rabbit: https://poly.pizza/m/3vvONbRCuEF by Poly by Google. Licensed Creative Commons Attribution 3.0 (CC BY 3.0): https://creativecommons.org/licenses/by/3.0/. The static Cottontail rabbit model is given a gentle hop in the scene.
